### Core Concepts
### 1. Recorder Schedule Spreadsheet
The central starting point for volunteers. Hosted on Google Drive and shared with the IRC team. Contains tabs including the recorder schedule, which lists upcoming retreats with columns for retreat type, dates, and recordist sign-up. Volunteers add their name to claim a retreat. Also contains a Dharma Talk Log where teachers fill in talk titles and a retreat info reminder link.
**Methods:**
- Open the Google spreadsheet shared via the IRC email address
- Navigate to the Recorder Schedule tab
- Identify retreat type on the left: residential, hybrid, day-long, or off-site
- Add your name to the recordist column to sign up
### 2. AudioDharma From-App Page
Talks recorded on-site using the iPad app on the podium are automatically uploaded to this page. It is not the starting page for workflow but is where uploaded files appear for editing. Files show the end time of the recording and the duration.
**Methods:**
- Access AudioDharma and log in with admin credentials
- Navigate to the from-app retreat page
- Identify talks by date and time matching the retreat schedule
- Cross-reference with the Dharma Talk Log to confirm talk titles and speakers
### 3. Editing Talk Metadata in AudioDharma Admin
Once logged in as admin, an Edit button appears on each talk. The edit page allows updating title, speakers, date, time, retreat series, venue, language, visibility, and podcast feed inclusion. Most fields are pre-filled from the iPad app upload.
**Worked Examples:**
- For the formal opening of retreat 8-9, Ernst located the talk, confirmed the 7:30 PM start time and 42-minute length, then edited the title from the Dharma Talk Log, added multiple speakers including G. Schultz who was not yet in the system, set the retreat to the Santa Cruz retreat entry, set venue to Insight Retreat Center, set dates to 8-9 through 8-16, and updated visibility
- For a talk with Q&A or yogi participation, visibility was set to retreatants only by code
- The podcast feed checkbox was unchecked as needed
**Methods:**
- Right-click the edit link and open in a new tab to keep the list page open
- Copy speaker names from the Dharma Talk Log
- If a speaker is not in the system, open the Speakers section in a new tab, search, and add them with name only if no bio or photo is available
- Set visibility: admin only while working, retreatants only by code for any talk with Q&A or yogi participation, public otherwise
- Uncheck the podcast feed option as appropriate
- Click Update Talk when done
### 4. Adding a New Retreat Entry
If a retreat has not yet been added to the AudioDharma system, it must be created before it can be assigned to talks. Retreats are listed in reverse chronological order.
**Methods:**
- Navigate to the Retreats section in AudioDharma admin
- Search for the retreat by name or date
- If not found, add a new retreat with the name, venue, and date range
- If the official retreat name is unknown, use a placeholder such as Insight Retreat and follow up with the coordinator for the correct name
### 5. Uploading a Processed Audio File
If a talk requires audio editing, the processed file is uploaded through the same edit page, replacing the original. The metadata already entered is preserved.
**Methods:**
- Download the original file from the talk page
- Save it to a local folder labeled IRC Raw
- Process the file using Audacity or other tools as needed
- Move the processed file to a folder labeled IRC To Upload
- On the edit page, use Choose File to select the processed file and upload it
- The filename of the uploaded file is displayed for confirmation
- Click Update Talk
**Worked Examples:**
- For a guided sit where the teacher stopped and restarted recording multiple times, resulting in several short files, the approach discussed was to download all fragments, review them in Audacity, and string them together with a short silence between each segment before uploading as a single file
### 6. Audio Quality and Processing
The AudioDharma system applies automatic gain adjustment and light noise reduction upon upload. Additional processing is optional and not required for most talks.
**Methods:**
- Check the beginning of each file for excessive silence and trim if needed
- Check the end for announcements that should be removed
- Optionally use iZotope mouth declick plugin for talks with microphone click artifacts, particularly Gil's recordings
- Use Audacity with VST plugins for any additional processing
- Do not feel obligated to listen through entire talks; visual inspection of the waveform in Audacity for obvious anomalies is sufficient
### 7. Final Notification Email to Deborah
After all recordings for a retreat are uploaded and verified, a notification email must be sent to Deborah. This triggers her to send an email to the retreat registrar. This step is frequently forgotten.
**Methods:**
- Verify all talks are visible and correctly listed by switching out of admin mode using the Viewing Admin toggle in the top right corner of AudioDharma
- Confirm all talks appear as retreatants would see them
- Copy the retreat access code from the retreat page
- Email Deborah with the code and confirmation that all recordings are uploaded
### 8. Retreat Types and Their Recording Processes
- **Residential:** Recorded on-site only via the iPad app on the podium. No live stream. Recordist processes and uploads files after the retreat ends, within approximately one week. Three talk types per day: morning guided sit, Dharma talk, and evening reflections, typically at 8:14, 16:00, and 20:45.
- **Hybrid/Webcast:** Residential retreat also attended by online participants via Zoom. Recordist attends the Zoom session and records it. Three backup layers exist: iPad app, Audio Hijack scheduled recording on the meditation hall laptop, and recordist's own home recording via Audio Hijack. Talks are processed and uploaded same day.
- **Day-long:** Online only, one-day retreat. Entered as a series in AudioDharma.
- **Off-site:** Managed through a separate platform, insightretreatonline.org, which requires separate login and admin access tied to being listed as the recordist on that retreat.
### 9. Login and Admin Access
Admin access to AudioDharma and InsightRetreatCenter.org is permanent once granted. Access to insightretreatonline.org is tied to being assigned as the recordist on a specific retreat by the registrar. - If login fails, use the lost password reset function

### Common Mistakes or Pitfalls
- Forgetting to send the final notification email to Deborah after uploading all retreat recordings; this is a frequently skipped step
- Assuming the work is done after uploading files without verifying visibility by switching out of admin mode
- Signing up for a retreat on the recorder schedule but not completing the full upload and notification workflow
- Attempting to log in with a personal email rather than the IRC-issued email address, which may block access to admin features
- Not checking whether a retreat entry exists in AudioDharma before trying to assign talks to it
- Spending excessive time on optional audio cleanup such as noise reduction or declicking when the automatic processing on upload is sufficient for most talks
- For hybrid retreats, failing to set up the scheduled Audio Hijack recording as a backup before the session begins

### Key Takeaways
- The recorder schedule Google spreadsheet is the single source of truth for knowing which retreats need a recordist and for signing up
- The full workflow ends only when Deborah receives the notification email with the retreat access code confirming all recordings are uploaded
- Admin access is permanent for AudioDharma and InsightRetreatCenter.org but must be activated per retreat on insightretreatonline.org
- Residential retreats are processed after the fact within about a week; hybrid retreats require same-day processing
- Audio quality processing beyond the automatic system adjustments is optional; most talks require only metadata editing and occasional trimming of silence or announcements
- Volunteers at IRC receive priority consideration for attending retreats, which are heavily oversubscribed
- Andy can perform all of this work remotely from any location with laptop access; no need to be on-site at IRC
