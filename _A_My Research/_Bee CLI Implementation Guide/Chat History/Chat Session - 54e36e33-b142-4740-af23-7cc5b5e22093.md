To gather your Bee data on Windows for your own AI and documentation, you can use the **Bee CLI** (`bee-cli`). This official command-line tool is specifically designed to export your personal data as markdown files and provide direct integrations for AI agents [1, 2].

Here is how you can set up your environment and extract your data:

**1. Enable Developer Mode on Android**
Before using the CLI on Windows, you must enable Developer Mode in your Bee Android app:

* Open the Bee app and go to **Settings** [3].
* Find the **Version** row and tap it **5 times** to unlock Developer Mode [3].

**2. Install and Authenticate the Bee CLI on Windows**
You can install the CLI using npm or by downloading the Windows release:

* **Via npm:** Run `npm install -g @beeai/cli` [4].
* **Via Download:** Download the `bee-windows-x64.zip` file from the Bee CLI GitHub releases page [5].
* Once installed, run `bee login` to authenticate with your Bee account [4].

**3. Gather Data for Documentation**
For documentation purposes, the easiest method is to export your data into standard Markdown files.

* Run the command `bee sync` [6].
* This will create a `bee-sync/` directory on your machine containing all your data organized into markdown files: `facts.md`, `todos.md`, and daily folders containing `summary.md` and your full conversation transcripts (`[ID].md`) [7, 8].
* After your first sync, subsequent `bee sync` commands will act incrementally, only fetching daily summaries and conversations that have changed [6].

**4. Connect Your Data to Your Own AI**
If you are building or using your own AI assistants (like Claude, Claude Code, or Codex), the Bee CLI offers specialized features to feed your data directly to the AI:

* **Model Context Protocol (MCP):** You can run the `bee mcp` command to turn your CLI into an MCP server. This allows AI assistants to natively read your Bee context, search conversations, and look up facts directly from your Windows machine without you needing to manage extra tokens [9, 10].
* **Agentic Sync:** If you are building custom AI agents, you can use the `bee changed` command to create an incremental sync loop. This gives your agent a feed of what has changed (new facts, todos, or conversations) since its last heartbeat so it can reason about what to do next [11, 12].
* **Real-time Streaming:** You can use `bee stream --agent` to pipe a live feed of your conversations and updates directly to your AI in a token-efficient, single-line format [13].
