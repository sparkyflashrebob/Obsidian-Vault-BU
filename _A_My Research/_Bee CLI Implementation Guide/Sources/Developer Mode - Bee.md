### Developer Mode

Developer Mode is required for Bee CLI and Bee Skill to connect to your Bee account.

#### Enable Developer Mode

##### Update to the latest Bee app

Open the App Store and make sure you are running the most recent Bee iOS app version.

##### Open Bee app settings

In the Bee app, open **Settings** .

##### Tap app version 5 times

Find the app **Version** row in settings and tap it **5 times** to unlock Developer Mode.

#### Verify it works

After unlocking Developer Mode, run:

```
bee login
bee status
```

If bee status shows you as authenticated, your setup is ready.
If CLI still cannot connect, update the app and repeat the 5 taps on Version.
