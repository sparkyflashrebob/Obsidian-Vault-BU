### Your AI, your memory

Bee captures your conversations and learns about you. Access your personal context through the CLI and connect AI agents with the Skill.
[Get Started](https://docs.bee.computer/docs) [View on GitHub](https://github.com/bee-computer/bee-cli) $ npm install -g @beeai/cli
Terminal

```
# Authenticate with your Bee account
$ bee login

# Get your daily brief
$ bee today
Good morning! You have 3 meetings today...

# See recent conversations
$ bee now
Found 5 conversations from the last 10 hours...

# Sync your data to markdown files
$ bee sync
Syncing facts... done
Syncing todos... done
Syncing conversations... done
```

#### Everything you need

Three ways to access and extend your personal AI memory.

##### Bee CLI

Command-line interface to access and export your Bee data. Sync conversations, facts, and todos to local markdown files.
\* Export to markdown
\* Real-time streaming
\* Local HTTP proxy
[Learn more](https://docs.bee.computer/docs)

##### MCP Server

Connect **Claude** , **Claude Code** , or **Codex** to your Bee context in one command. The CLI doubles as a Model Context Protocol server using your existing login.
\* One-command setup
\* Claude, Claude Code & Codex
\* Data stays on your machine
[Learn more](https://docs.bee.computer/docs/mcp)

##### Bee Skill

Connect AI agents to your personal context. Give your AI assistants real-time awareness of your conversations and knowledge.
\* Real-time context
\* Personal knowledge base
\* End-to-end encrypted
[Learn more](https://docs.bee.computer/docs/skill)
