Developer Mode for the Bee Pioneer and the Bee AI app is primarily designed for the iOS version and for using the Bee Developer Docs. Because the Android app is currently an early-access build, the steps to enable developer tools on Android require unlocking your phone's native developer settings and using command line tools. [1, 2, 3, 4]
Part 1: Unlock Phone Developer Options To allow for advanced debugging and integration, you must first unhide developer options on your Android device:

1. Open your device's Settings menu.
2. Scroll to and tap About Phone (or About Device).
3. Select Software Information (or Version).
4. Locate the Build Number and tap it exactly 7 times in rapid succession.
5. Enter your phone's PIN or passcode when prompted to confirm.
6. Go back to the main Settings menu to access the newly visible Developer Options. [6, 7, 8, 9]
   Part 2: Enable USB Debugging Once unlocked, you need to enable debugging to connect your phone to the Bee CLI:
7. Open Developer Options in your Settings.
8. Scroll down and toggle on USB Debugging.
9. Connect your Android device to your computer via USB to use Bee Developer Docs and build integrations. [3, 10, 11, 12]
   Part 3: App-Level Developer Mode If you are specifically trying to unlock features in the Bee AI app to sync data or build scripts, refer to the Bee Developer Docs to pair your CLI. [4]
   If you are using the Bee Pioneer early-access Android app, note that active development support is limited. If you would like to test unofficial workarounds to get the bracelet working, you can read user discussions on the Android community forum. [1, 13]
