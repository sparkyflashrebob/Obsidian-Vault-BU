Teaching Reflection on Calm
From Ajahn Nyaniko AMTR 2021 Day 3 Morning Reflection

So taking a few minutes just to bring to mind recollecting a sense of ease and well-being.

When we are doing a lot or we have a lot of things coming our way, we have to make a lot of quick decisions, then the body can start to get a bit tense.

But if we can use the dhamma, if there is tension, it can be quickly dissipated by taking a deep breath - consciously __**calming**__ the bodily formation.

Pause

And when the mind is a bit more comfortable the body will tend to be more comfortable.
When the mind is agitated the body will tend to be agitated.

Pause

So the body and the mind are connected in this way, so with the meditation, we can actually consciously calm the body.
And we can take it the other way as well. By consciously calling the body we can keep the mind from being too stirred up.

Pause

And, although the Buddha doesn't talk about stopping our thinking, he does speak in praise of it when it stops from a natural setting. That's what we call the vaci sankhara, the verbal formation, the constant natting, the constant commentator. So when don't hold onto anything then the commentator doesn't have much to say. That's like a sports commentator but there is nothing happening on the field. So there is not much to talk about. If there are no players on the field there is not much to talk about.

Pause

And yet we are doing something with the meditation. We are putting effort into the practice thru these recollections, the contemplations. We just don't let the mind go down the stream it has always been going down.

Pause

I can't stress enough the recollection of impermanence. Any work, any good deed, any skill, any talent, all things good and bad, bodily or mental - all impermanent.
Moods, thoughts, emotions, they are all inconstant passing thru. So in meditation, we recollect that, at least temporarily we try to drop things. And we drop things it is temporary too. After this meditation period we will pick them back up again. But at least we can feel that lightness temporarily. And recollect it, it can become a refuge for us. We can default back to this.

Pause

So Ajahn Chah taught us if there is a heavy rock in front of us it is not heavy if we don't pick it up. So can think we are surrounded by heavy rocks, by heavy things, we don't have to pick them up. They are not a burden if we don't pick them up.
But the mind is telling us there is some benefit to picking them up there is some benefit of carrying heavy weights but if we reflect on it we see it's suffering every time.
And we have been trying this for a very long time. So it's worth dropping everything. At least for the time being.

Pause

So we might think "I’ve been holding onto these things for so long how can I drop them? What does that say about me if I have been holding onto them for so long? I should keep holding on by virtue of the fact that I have been holding for such a long time, if I drop it, what does that say about all the work that I have done to hold onto everything for so long."
It doesn't matter in the moment,  it will be that much lighter, if we drop it, it will be that much lighter.
You'll feel a sense of relief, I don't have to prop that anymore, hold that up anymore. I can breathe easy.
