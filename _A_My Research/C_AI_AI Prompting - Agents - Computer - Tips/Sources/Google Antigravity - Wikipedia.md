**Google Antigravity** is a software development platform developed by [Google](https://en.wikipedia.org/wiki/Google). It consists of an [integrated development environment](https://en.wikipedia.org/wiki/Integrated_development_environment) (IDE), a [command-line interface](https://en.wikipedia.org/wiki/Command-line_interface) (CLI), and a [software development kit](https://en.wikipedia.org/wiki/Software_development_kit) (SDK) designed to orchestrate autonomous [artificial intelligence](https://en.wikipedia.org/wiki/Artificial_intelligence) agents for code generation, execution, and testing.

#### Integrated development environment

[ [edit](https://en.wikipedia.org/w/index.php?title=Google_Antigravity&action=edit&section=1)]
Announced on November 18, 2025 alongside the release of [Gemini](https://en.wikipedia.org/wiki/Gemini_(language_model)) 3, Antigravity enables developers to delegate complex coding tasks to autonomous AI agents powered primarily by Google's Gemini 3.1 Pro [\[5\]](https://en.wikipedia.org/wiki/Google_Antigravity#cite_note-Preston-2025-5) and Gemini 3 Flash models. [\[6\]](https://en.wikipedia.org/wiki/Google_Antigravity#cite_note-6) The platform is a heavily modified fork of [Visual Studio Code](https://en.wikipedia.org/wiki/Visual_Studio_Code) (VS Code). There is debate as to whether it is a direct fork of the software, or whether it is a fork of [Windsurf](https://en.wikipedia.org/wiki/Cognition_AI), another AI-oriented code editor which is itself a fork of VS Code. [\[7\]](https://en.wikipedia.org/wiki/Google_Antigravity#cite_note-7) Google Antigravity supports multiple AI models, including [Anthropic's](https://en.wikipedia.org/wiki/Anthropic) [Claude Sonnet](https://en.wikipedia.org/wiki/Claude_(language_model)) 4.6 and Claude Opus 4.6, as well as an [open-source](https://en.wikipedia.org/wiki/Open_source) variant of [OpenAI](https://en.wikipedia.org/wiki/OpenAI) models (GPT-OSS-120B). [\[8\]](https://en.wikipedia.org/wiki/Google_Antigravity#cite_note-8)
Antigravity was released in public preview on the day of its announcement and is available free of charge for [Microsoft Windows](https://en.wikipedia.org/wiki/Microsoft_Windows), [macOS](https://en.wikipedia.org/wiki/MacOS), and [Linux](https://en.wikipedia.org/wiki/Linux), with "generous [rate limits](https://en.wikipedia.org/wiki/Rate_limiting)" for Gemini 3.1 Pro usage. [\[5\]](https://en.wikipedia.org/wiki/Google_Antigravity#cite_note-Preston-2025-5)

##### Features

[ [edit](https://en.wikipedia.org/w/index.php?title=Google_Antigravity&action=edit&section=2)]
Antigravity introduces an "agent-first" [paradigm](https://en.wikipedia.org/wiki/Paradigm), shifting from traditional AI code assistance to a system where AI agents operate with greater autonomy. It features two primary views:
\* Editor view: A usual IDE interface like VS Code and [PyCharm](https://en.wikipedia.org/wiki/PyCharm) with an agent sidebar, similar to tools like [Cursor](https://en.wikipedia.org/wiki/Cursor_(code_editor)) or [GitHub Copilot](https://en.wikipedia.org/wiki/GitHub_Copilot).
\* Manager view: A control center for orchestrating multiple agents working in parallel across workspaces, allowing asynchronous task execution. [\[9\]](https://en.wikipedia.org/wiki/Google_Antigravity#cite_note-9)
To build user trust, agents generate "Artifacts"—verifiable deliverables such as task lists, implementation plans, screenshots, and [browser](https://en.wikipedia.org/wiki/Web_browser) recordings—rather than raw tool calls. [\[10\]](https://en.wikipedia.org/wiki/Google_Antigravity#cite_note-10) Agents have direct access to the editor, [terminal](https://en.wikipedia.org/wiki/Computer_terminal), and a integrated browser, and can learn from previous interactions. [\[11\]](https://en.wikipedia.org/wiki/Google_Antigravity#cite_note-11)
