1. Log Entry: 07:52 AM
The initial morning discussion centered on critical drawing revisions for the town hall and Penta projects, prompted by newly identified discrepancies in ceiling heights and equipment specifications. The strategic importance of resolving these design issues promptly was emphasized to prevent downstream installation errors and ensure the accuracy of construction documents.
Discussion Summary
Errors were discovered on the town hall drawings, specifically an inverted camera orientation and an incorrect ceiling height that requires adjustment to 9'4". A subsequent review of the Bill of Materials (BOM) confirmed that an "ovation" lighting item, which was mistakenly included, must be removed. A collaborative Blue Beam session was held to finalize the new lighting layout, establishing a plan with Quad lights positioned on the outside and Accent lights in the middle. The inverted camera orientation, combined with the new lowered ceiling height, makes the original mount unusable and requires a new ceiling mount solution, with an all-thread system proposed as a potential option. The significant volume of architectural drawing updates for the Penta project was delegated to the CAD team to expedite the revision process.
Action Items
• Drawing Revisions: Update town hall drawings to invert the camera, correct the ceiling height to 9'4", and drop the ceiling infrastructure accordingly.
• BOM Correction: Remove the "ovation" item from the project Bill of Materials.
• Lighting Layout: Update the Blue Beam drawing set to reflect the confirmed lighting plan: Quad lights on the outside and Accent lights in the middle.
• Camera Mount: Design and specify a new ceiling mount solution for the camera, potentially using an all-thread system.
• Coordination: Discuss the proposed camera mount and above-deck conditions with Miguel.
• Task Delegation: Assign the significant architectural drawing updates for the Penta project ceiling changes to Will (CAD).
These design revisions led directly to a subsequent discussion regarding the physical infrastructure required to support the updated equipment plans.

1. Log Entry: 09:52 AM
The conversation shifted to the foundational AV infrastructure, focusing on network requirements and the complex challenge of speaker selection and placement within specific architectural constraints in the reception and break room areas.
Discussion Summary
An initial network port count estimate of approximately 20 ports was established, leading to the decision to repurpose an existing, unallocated network switch for AV equipment. The proposed solution is to mount the speakers above the grid, which requires precise field measurements of the grid's thickness.
To ensure accurate placement, a formal request was made to the client (Gina) for a complete ceiling layout drawing that includes grid reference lines. For the break room, a detailed alternative was discussed, proposing the use of surface-mount speakers on soffits or columns to avoid conflicts with the unique ceiling treatment in that area.
Action Items
• Networking: Procure or allocate a network switch with approximately 20+ ports for AV equipment.
• Field Measurement: Instruct Miguel to measure the ceiling grid thickness in the reception area to inform the speaker mounting strategy.
• Client Deliverable: Request a complete ceiling layout drawing with grid reference lines from Gina to ensure accurate speaker placement.
• Drawing Update: Update design documents to specify that pendant speakers will be hung at 10' 6" Above Finished Floor (AFF).
• System Design: Finalize the speaker solution for the break room, deciding between pendant and surface-mount options and creating a corresponding layout that ensures proper audio coverage.

1. Log Entry: 01:52 PM
A significant, system-level problem was identified with the specified Adder KVM system, revealing a critical incompatibility with the project's Mac-based ecosystem that requires an immediate redesign of that subsystem.
Discussion Summary
The core issue is that the Adder KVM system is not fully Mac-compatible. This incompatibility manifests in a critical failure where the mouse cursor cannot move to the second display when using the system's multiviewer functionality. This failure occurred despite extensive pre-sale consultations and bench testing with the manufacturer, which is a source of considerable frustration. A replacement solution is now required and must meet several non-negotiable criteria: it must be fully Mac-compatible, support dual displays for each operator station, and feature an external control API (via LAN or RS-232) to allow for seamless integration with the project's Crestron control system (CUCIs).
Action Items
• System Redesign: Immediately source a new KVM system that is fully Mac-compatible and supports dual displays.
• Control Integration: Ensure the replacement KVM solution includes a control API (LAN or RS-232) to allow for integration with the CUCI control panels.
• Peripheral Replacement: Specify and source new keyboard and mouse extenders that are also confirmed to be fully Mac-compatible.
Following the urgent KVM redesign task, the day concluded with a review of other key equipment specifications.
