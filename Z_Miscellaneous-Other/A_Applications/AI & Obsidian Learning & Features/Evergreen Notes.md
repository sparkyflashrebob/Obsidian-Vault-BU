#####Markdown

Notes are written in markdown. Markdown is a simple syntax to format the document as you write it. Type from one to five #hashtags to create headings, like so:
#####
####
###
##
#
If you hit the preview button (the eye) in the toolbar above, you will see the special syntax removed.

There is also syntax for **bold**, *italics*, ~~strikethrough~~, etc.

Markdown is very simple to learn. You can read more about it [here](https://www.markdownguide.org/getting-started/) if you are interested. 



#####Evergreen Notes Hotkeys
* Alt + Arrow Keys: switch between the different panes.
* When creating a link with double brackets, press Escape to hide the list of other links and press Escape again to cancel creating a link.
