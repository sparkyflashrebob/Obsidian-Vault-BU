Loving Universe,
Make me an instrument of peace;
that where there is hatred, let me show love;
that where there is injury, pardon;
that where there is doubt, faith;
that where there is despair, hope;
that where there is darkness, light,
and where there is sadness, joy.

Grant that I do not so much seek to be consoled as to console;
to be understood as to understand;
to be loved as to love;
for it is in giving that we receive;
it is in pardoning that we are pardoned;
and it is in the letting go that we are reborn into each moment.
