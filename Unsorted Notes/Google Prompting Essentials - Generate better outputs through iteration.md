
# Iteration
sometimes will not get the results you are looking for
that is what iteration is for
- to clarify and refine you prompt
- a few types
	- able to break thru creative blocks
- prompt in the same chat 
	- references info from previous prompts and build on that knowledge 

prompts that only include the task 
-  might provide broad insights but chances are good there will be a need to iterate more

## Four Iteration Methods
1. Revisit the prompting framework
2. break the prompt into shorter sentences
3. tweak your phrasing or switch to analogous task
4. Introduce constraints

### Revisit Prompt Framework
- make sure to have a specific persona & format, plenty of context, and offers relevant reference 

### Break prompt into shorter sentences
- step into it

### Tweak your Phrasing or switch to analogous task
- shift language to explain what you mean in a different way
- try a different task that is similar to what you have been trying

### Introduce Constraints
- set boundaries for specific categories, lengths, formates, or other details
- can encourage to be more inventive
